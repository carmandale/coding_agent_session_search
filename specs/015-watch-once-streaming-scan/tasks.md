Ordered checklist for the implementer. Plan source of truth lives in [`plan.md`](plan.md); spec is [`spec.md`](spec.md). Tasks are grouped under H2 headers — `/codex-implement` chunks at group boundaries for per-chunk Codex validation.

## Group A — Helpers and scratch-root infrastructure

- [x] T1: Add `src/indexer/scratch_root.rs` (or inline submodule in `src/indexer/mod.rs`) with `ScratchRootGuard` (RAII path wrapper that `Drop`s with `std::fs::remove_dir_all`), `build_scratch_root(batch: &[DiscoveredSourceFile], workdir: &Path, original_sessions_root: &Path) -> Result<(ScratchRootGuard, Vec<ScratchBuildSkip>)>`, and `derive_pi_sessions_root(scan_root: &Path) -> PathBuf` (FAD-equivalent: if `scan_root/sessions` exists return that, else return `scan_root` — handles both `--watch-once ~/.pi/agent` and `--watch-once ~/.pi/agent/sessions`). Builder strips each source file's `original_sessions_root` prefix and recreates the relative subtree under `<scratch>/sessions/<rel>`. Hardlink first via `std::fs::hard_link`; on `EXDEV` fall back to `std::fs::copy` (APFS clonefile on macOS). On per-file non-EXDEV failure (missing source, permission, etc.), record a `ScratchBuildSkip { source_path, error_message }` and continue with the rest of the batch (Codex-review Round 1 finding — scratch-build failures must NOT abort the run; they're skip records). Only systemic errors (workdir creation failure, scratch root permission issues) propagate. Default `workdir = <data_dir>/scratch/watch-once-streaming/`. Uses `tempfile::Builder::tempdir_in().keep()` for the per-batch subdir name (matches existing cass tempdir convention; avoids adding a uuid dep).
- [x] T2: Add `remap_source_path_field(source_path: &mut PathBuf, scratch_sessions_root: &Path, original_sessions_root: &Path)` that strips `<scratch>/sessions` prefix and rejoins under `<original>/sessions`. No-op if the path doesn't have the scratch_sessions prefix (defensive). Placed in `src/indexer/scratch_root.rs` for cohesion with the scratch builder. Two-prefix form (not single-prefix) avoids the duplicated `sessions` segment.
- [x] T3: Defined `ScanBatchLimits { max_files: usize, max_bytes: u64 }` plus an env-loader that reads `CASS_WATCH_SCAN_BATCH_FILES` (default 50), `CASS_WATCH_SCAN_BATCH_BYTES` (default 64 MB). Plus a `chunk_by_files_and_bytes` helper that yields batches of `DiscoveredSourceFile`, flushing whichever scan limit fires first. Bytes drawn from `DiscoveredSourceFile.size_bytes`. Messages-at-scan limit dropped because `DiscoveredSourceFile` carries `size_bytes` per `scan.rs:205-217` but no message count is available pre-scan. Message-count gating lives at the post-scan buffer-flush boundary (T7) where actual `NormalizedConversation.messages.len()` is known; that's a separate knob (`CASS_WATCH_BUFFER_MAX_MESSAGES`, default 8,192).
- [x] T4: Unit tests for helpers (13 tests, all passing): scratch_root builder copy-fallback path (`build_scratch_root_hardlinks_files_into_canonical_layout`), scratch-build per-file skip path (`build_scratch_root_records_missing_file_as_skip`, `build_scratch_root_records_path_outside_root_as_skip`), remap idempotence + correctness for the `<scratch>/sessions/<ws>/<file> ↔ <original>/sessions/<ws>/<file>` mapping (`remap_source_path_field_translates_scratch_to_original`, `remap_source_path_field_is_noop_when_prefix_absent`), `derive_pi_sessions_root` correctness for both `~/.pi/agent` and `~/.pi/agent/sessions` input shapes (`derive_pi_sessions_root_prefers_subdir_when_exists`, `_returns_input_when_subdir_missing`, `_handles_both_canonical_user_inputs`), chunker boundary conditions (`chunk_by_files_and_bytes_empty_input`, `_files_limit`, `_bytes_limit`, `_oversized_single_file`), RAII cleanup (`scratch_root_guard_drops_directory` — verifies `metadata` returns `NotFound` after guard drop, per Phase B Round 3).
